# Reference Materials

이 폴더에는 프로젝트의 공식 작업 흐름과 분리해 보관할 참고자료가 들어 있다.

## personal_prework

스터디 공동 작업 당시 팀원들을 지원하고 이후 단계를 미리 검토하기 위해 개인적으로 수행한 선행 분석이다.

- 테이블별 EDA와 데이터 품질 검증
- 전체 OULAD 종합 분석
- 초기 전처리와 Random Forest 모델 실험

이 자료는 분석 방향과 구현 아이디어를 재사용하기 위한 참고용이다. 모델링용 통합 테이블이 확정되기 전에 작성됐으므로 최종 데이터·모델·성과로 간주하지 않는다. 개인 작업을 이어갈 때 유효한 처리 원칙은 재검증한 뒤 공식 노트북에 반영한다.
