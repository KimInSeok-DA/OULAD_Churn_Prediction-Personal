## 1. 배경

최종 모델 확정 전 파이프라인 전체 검증에서 평가 피처 정의의 문제 두 가지가 발견됐다.
계산 오류는 아니었다(원본에서 독립 재계산 시 불일치 0건). 둘 다 **정의가 과목·학기 구조 변화와 재수강 이력을 반영하지 못한** 문제다.

### 1.1 BBB 2014J 평가 일정 변경

| BBB 학기 | 개강 후 60일까지 TMA/CMA (마감일, 가중치) |
|---|---|
| 2013B | TMA 19일(5), TMA 47일(18), CMA 54일(1) |
| 2013J | TMA 19일(5), TMA 47일(18), CMA 54일(1) |
| 2014B | TMA 12일(5), TMA 40일(18), CMA 47일(1) |
| **2014J** | **TMA 19일(0)**, TMA 54일(10) |

- 2014J의 19일 TMA는 이전 학기 첫 TMA와 같은 위치지만 **가중치만 5 → 0**으로 바뀌었다. 학생들은 이 평가를 실제로 제출했다.
- 기존 정의(`weight > 0`)에서는 2014J BBB 모델 대상 1,776명 전원이 `n_opportunity_25 = 0`이 된다. 개발 학기에서는 한 번도 없던
  **"BBB × 기회 0"** 조합이 holdout에서 처음 나타난다.
- 25일 안에 마감되는 가중치 0 TMA/CMA는 **BBB 2014J의 1건뿐**이다. 가중치 조건을 없애도 다른 과목·학기의 값은 변하지 않는다.

### 1.2 이월(banked) 재수강생

- 기존 정의는 기회 수를 과목 단위로 셌고, 제출은 `is_banked == 0`만 인정했다.
- 그 결과 25일 내 기회 평가를 이월받은 재수강생 464명 전원이 **"기회는 있었는데 하나도 안 냈다"**로 기록됐다.
- 이월자의 실제 이탈률은 24.8%다. 이월 없이 실제로 전부 미제출한 학생의 이탈률은 42.2%다. 성격이 다른 두 집단이 같은 피처 값으로 섞였다.

## 2. 고려한 대안

### 2.1 가중치 조건

| 대안 | 내용 | 판단 |
|---|---|---|
| **A (채택)** | `weight` 조건 삭제, 25일 내 마감 TMA/CMA 전체를 기회로 봄 | BBB 2014J 구조 단절 해소, 다른 학기 영향 없음 |
| B | 계약 유지 + "25일 내 제출한 전체 TMA/CMA 수" 별도 피처 | 계약은 유지되지만 `n_opportunity_25 = 0` 불일치는 남음 |
| C | 계약 유지 + 문서화·배포 경고만 | 문제 해결 안 됨 |

### 2.2 이월 처리

| 대안 | 내용 | 판단 |
|---|---|---|
| **기회에서 제외 + 플래그 (채택)** | 이월 평가를 학생별 기회에서 빼고 `n_banked_25` 추가 | 미제출 신호 오염 제거, 재수강 정보 보존 |
| 제출로 인정 | 이월을 제출 1건으로 세고 이월 점수를 `avg_score_25`에 포함 | 25일 내 실제 행동과 과거 성적이 섞임 |
| 플래그만 추가 | 기존 정의 유지 + `n_banked_25` | 미제출 의미의 오염이 그대로 남음 |

## 3. 최종 결정

```
기회 후보   = 25일까지 마감된 TMA/CMA (weight 무관), 과목-학기 단위
n_banked_25 = 기회 후보 중 그 학생이 is_banked = 1로 받은 개수
n_opportunity_25 = 기회 후보 수 − n_banked_25   (학생마다 다를 수 있음)
n_submitted_25   = 기회 후보 중 is_banked = 0 이고 date_submitted <= 25 인 제출 수
```

- `n_missing_25`, `submission_rate_25`, `no_assessment_opportunity_25`, `avg_score_25`, `avg_submit_delay_25`는 위 정의에서 기존과 같은 방식으로 파생한다.
- `n_banked_25`는 최종 모델 피처에 포함한다(`05_Collinearity_Recheck` 4.5절, VIF 1.19).
- 프로젝트 데이터 계약 문구(`docs/데이터_사전.md`)를 "N일까지 마감된 TMA/CMA(가중치 무관) 중 학생에게 이월되지 않은 평가"로 바꾼다.

## 5. 성능 영향과 주의점

같은 Logistic 설정, 같은 fold로 비교했다(PR-AUC).

| 비교 | 변경 전 | 변경 후 | 변경 후 + `n_banked_25` |
|---|---:|---:|---:|
| **모델링 개발 세트 CV (2013B·2013J·2014B)** | 0.3962 | 0.3989 | **0.3994** |
| └ 이월 행 | 0.3023 | 0.3084 | 0.3165 |
| 4개 학기 전체를 섞은 CV (`05` 4.4절) | 0.3903 | 0.3856 | 0.3858 |
| └ BBB 2014J 행 | 0.1840 | 0.2087 | 0.2089 |
| └ 값이 그대로인 나머지 행 | 0.4020 | 0.3957 | 0.3955 |

> **2026-09-15 재현 안내**: "변경 후" 두 열은 `05_Collinearity_Recheck` 4.4절 재현 코드로 다시 계산했다. 전체 CV와 나머지 행은 위 표와 같고,
> 부분 집합 값은 BBB 2014J 0.2088 / 0.2089, 4개 학기 이월 행 0.2969 / 0.2995, 개발 세트 이월 행 0.3084 / **0.3180**으로 소수 셋째 자리에서만 다르다(방향·결론 동일).
> "변경 전" 열은 변경 전 통합 정본을 보관하지 않아 당시 기록으로 남긴다.

- **실제 모델링 방식(개발 세트 CV)에서는 개선**된다.
- 4개 학기를 섞은 CV에서만 떨어지는데, 바뀐 행 자체는 좋아졌고 **값이 그대로인 행이 떨어졌다.** BBB 2014J의 19일 TMA는
  **가중치 0이라 점수 성격이 다르기 때문**이다. 평균 점수는 59.2점으로 다른 BBB 학기(71.8점)보다 낮고, 미제출 이탈률도 26.3%로
  다른 BBB 학기(35.1%)보다 약하다. 한 모델에 섞이면 공통 계수를 흐린다.
- 실제 모델링은 2014J를 학습에 쓰지 않으므로 이 혼입은 생기지 않는다. 다만 **holdout에서는 개발 학기의 "가중 TMA 점수"로 학습한
  모델을 "가중치 0 TMA 점수"에 적용**한다. 따라서 holdout BBB 결과는 이 차이를 함께 해석한다.

## 6. 트레이드오프와 한계

- **계약 변경**: "성적에 반영되는 평가만 기회"라는 해석 단순성을 잃는다. 대신 "25일 안에 낼 과제가 있었는가"라는 행동 관점과 맞는다.
- **가중치 0 평가의 의미 차이**: 가중치 0 평가는 가중 평가보다 학생이 덜 성실하게 임할 수 있다(BBB 2014J 점수가 12.6점 낮음).
  배포 시 새 학기 일정에 가중치 0 평가가 25일 안에 있으면 같은 주의가 필요하다.
- **`n_opportunity_25`의 성격 변화**: 과목 일정 속성에서 "과목 일정 − 이월"로 바뀌어 학생마다 다를 수 있다. 항등식은 그대로 성립한다.
