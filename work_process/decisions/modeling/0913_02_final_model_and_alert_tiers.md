## 2. 최종 모델: 왜 XGBoost인가

| 기준 | Logistic | RandomForest | XGBoost | 출처 |
|---|---:|---:|---:|---|
| CV PR-AUC | 0.4004 | **0.4061** | 0.4055 | 01 9절 |
| 학기 단위 PR-AUC 평균 / 최소 | 0.318 / 0.311 | 0.343 / 0.296 | **0.360 / 0.324** | 01 6절 |
| 중요도 fold 간 안정성 | 0.825 | 0.825 | **0.840** | 02 4절 |
| 과목 간 차이 의존도 | 43% | **26%** | 30% | 02 4절 |
| 학생별 설명(SHAP) | 계수 | 불가(추가 패키지 필요) | **내장** | 02 7절 |
| 튜닝 시간 | 8초 | 523초 | 108초 | 01 5절 |

- CV에서 RandomForest와 **동점**(차이 0.0006 < fold 표준편차 0.015)이므로, 사전 규칙상 챔피언(RF)보다 **운영 관점**을 우선했다.
  - **새 학기에 적용했을 때의 평균·최저 성능이 가장 높다**(학기 단위 0.360 / 0.324). 흔들림 폭 자체는 Logistic(0.015)이 가장 작지만 성능이 가장 낮다. 새 학기 데이터로 계속 쓰는 예측 모델이라는 목적에 맞는다.
  - **개별 학생의 위험 요인을 관리자에게 설명할 수 있다**(SHAP 내장).
  - **재학습·재튜닝 부담이 작다.**
- 이탈 요인 해석은 RandomForest와 사실상 같다(순위 상관 0.914). 모델을 바꿔도 P5 해석은 흔들리지 않는다.
- Logistic은 과목 간 차이 의존도가 가장 높고(43%) 학기 단위 성능이 가장 낮아 예측 모델에서 제외하되, **오즈비 설명 보조**로 유지한다.

**holdout 관련 기록**: 01에서 RandomForest holdout(PR-AUC 0.3649)을 평가한 뒤 모델을 XGBoost로 정했고, 03에서 XGBoost holdout을 처음 평가했다(0.3572, RF보다 0.008 낮음).
결정은 **개발 세트 근거로 먼저 내렸고 holdout 수치를 보고 바꾸지 않았다.** 이 차이는 학기 단위 검증의 모델별 흔들림(RF 0.095, XGBoost 0.074)보다 작다.

## 3. 결과 전달 대상: 왜 관리자인가

| 관점 | 학생에게 직접 경고 | 관리자에게 명단 전달 (채택) |
|---|---|---|
| 효과 | 위험군 통보가 낙인이 되거나 이탈을 굳힐 수 있음 | 관리자가 학생 사정에 맞는 대응(연락, 일정 조정, 학업 지원)을 선택 |
| 오탐 비용 | 이탈하지 않을 학생에게 불안을 줌 | 관리자의 확인 시간만 소요 |
| 판단 주체 | 모델 점수가 곧 결론 | 모델은 우선순위, 판단은 사람 |
| 공정성 | 인구통계 요인이 섞인 점수를 학생이 그대로 받음 | 관리자가 행동 신호와 함께 판단 |

학생용 리마인더(마감 알림 등)는 **위험도와 관계없이 전원**에게 보낸다.

## 6. 단일 기준 방식을 쓰지 않은 이유

| 방식 (개발 세트) | 관리자 명단 | Recall | Precision | GGG Recall | 한계 |
|---|---:|---:|---:|---:|---|
| F1 최대 단일 (0.211) | 31.3% | 59.0% | 35.9% | 0.0% | 대응 강도 구분 불가, 2차 점검 대상 정의 불가, GGG 방치 |
| Recall 80% 선 단일 (0.13) | 56.5% | 80.0% | 27.0% | 6.9% | 재학생 절반 이상이 관리자 대응 대상 → 과부하 |
| 전역 상위 20% 단일 | 20.0% | 44.1% | 42.0% | 0.0% | 이탈자 절반 이상 누락 |
| 과목 내 상위 30%만 | 30.0% | 51.0% | 32.4% | 36.3% | 고이탈 과목(CCC·DDD)의 고위험 학생까지 30%로 잘림 |
| **A안 관리자 명단(1+2)** | 33.5% | 61.1% | 34.8% | 0.0% | |
| **A안 인지 범위(1~3)** | 58.8% | 80.8% | 26.2% | 36.3% | |

**핵심 논리**: 단일 기준은 인지 범위, 관리자 부담, 과목 형평 중 최소 하나를 포기해야 한다.
A안은 **인지는 Recall 80% 선만큼 넓게, 관리자 직접 대응은 F1 최대 기준만큼 좁게, 과목 형평은 과목 내 순위로 보완**한다.

## 7. holdout(2014J) 확인 결과 — 1회 평가

| 항목 | 개발 OOF | holdout |
|---|---:|---:|
| PR-AUC (이탈률 대비) | 0.403 (2.11배) | 0.357 (1.90배) |
| 평균 예측 / 실제 이탈률 | 19.1% / 19.1% | 18.0% / 18.8% |
| 고위험 / 주의 / 관찰 / 일반 **실제 이탈률** | 48.1 / 28.1 / 14.8 / 8.9% | **47.0 / 26.9 / 17.7 / 10.1%** |
| 관리자 명단(1+2) / Recall | 33.5% / 61.1% | 34.2% / 56.1% |
| 인지 범위(1~3) / Recall | 58.8% / 80.8% | 55.5% / 76.2% |
| GGG 인지율(1~3) | 36.3% | 45.7% |
| 26–32일 이탈자 중 고위험·주의 | 89.7% | 75.0% |

- **등급별 실제 이탈률이 ±3%p 안에서 유지**되어, 새 학기에도 등급의 의미가 통한다.
- 대안 기준을 holdout에 사후 적용해도 A안의 우위가 유지된다. 비슷한 인지 규모에서 Recall 80% 단일 기준보다 Recall이 +2.4%p 높고, GGG는 0%에서 45.7%로 올라간다(선택 변경에는 사용하지 않음).
