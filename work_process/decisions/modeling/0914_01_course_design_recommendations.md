# 0914_01 목적별 과목 설계 제안 — 근거 판정 기준과 제안 강도

- 날짜: 2026-09-14
- 상태: 확정 (인과 효과가 아닌 설계 가설과 근거 강도)
- 근거: `Notebooks/03_Modeling/07_Course_Design_Indicators.ipynb`, `CSV_files/모델링/course_design_indicators_n25.csv`, `course_design_evidence_n25.csv`, `course_design_did_n25.csv`

## 1. 배경

- 문제 제기: 예측이 잘 되는 과목·이탈이 적은 과목의 성격(기간·과제·평가 등)을 정량으로 추려, 목적에 따라 과목 설계를 제안하자.
- 확인한 사실: "예측이 잘 되는 과목"과 "이탈이 적은 과목"은 다르다(GGG는 이탈 최저이면서 탐지 최저). 따라서 목적을 나눠 제안한다.

## 2. 분석 설계 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 단위 | 과목×학기 22개 | 설계가 학기마다 바뀜 |
| 목적 | A 재학 유지 / B 학업 성취(완주자 합격률) / C 조기 탐지(학기별 ROC-AUC, PR-AUC 배수) / D 관리자 운영(명단 비율) / E 재학습 안정성 | 목적마다 "좋은 과목"이 다름 |
| 교란 대응 | Spearman 상관을 ① 전체 ② 과목 내 ③ 과목·학기 고정효과 잔차 ④ 과목 평균(n=7)에서 비교 | 분야·학생 구성·개강 시기가 설계와 묶여 있음 |
| 판정 | ③이 뚜렷(|r| ≥ 0.3)하고 3개 수준 이상 같은 부호면 "일관". ①·④만 뚜렷하면 "과목 간 차이만"으로 설계 근거에서 제외 | 처음 규칙(뚜렷한 수준 개수만 셈)은 교란 관계를 "부분"으로 분류해 실행 결과 확인 후 수정 |
| 사례 | 같은 과목 설계 변경 5건 이중차분(대조: 같은 기간 두 학기가 있는 다른 과목) | 과목 자체를 통제 |

## 3. 결과와 제안 강도

| 목적 | 제안 | 강도 |
|---|---|---|
| C | 3–4주 안 첫 평가에 성적 가중치 (가중치 낮춘 S1·S2·S5 모두 ROC-AUC −0.06 ~ −0.09) | 강 |
| C | 초기 3–4주 참여 활동 설계 (25일 클릭 × 성능 일관) | 중 |
| C | 25일 내 평가 없는 과목(GGG) 조기 체크포인트 | 중 |
| B | 간격을 둔 소수 핵심 평가 (평가 수 × 합격률 −0.5 ~ −0.8, S1 +4.6%p, S5 −6.8%p) | 중 — 성적 산출 방식 변화와 구분 불가 |
| A | 설계로 이탈 감소 제안 안 함, 실험 후보로만 (통제 후 일관 관계 없음, 사례 혼재) | 약 |
| D | 초기 평가 도입 시 인력 계획 (명단 비율 +0.46 ~ +0.80, S1·S5 +18%p) | 강 |
| E | 학기 간 일정·가중치 유지, 변경 시 배포 전 점검 (S1 PR-AUC 배수 −0.58) | 강 |
| — | 과목 기간 조정 (개강 시기 B·J 효과) | 근거 없음 |
