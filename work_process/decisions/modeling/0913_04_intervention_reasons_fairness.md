## 1. 위험 사유 코드

| 항목 | 결정 |
|---|---|
| 방법 | 최종 XGBoost 학생별 SHAP(`pred_contribs`, 보정 전 log-odds)을 사유 범주로 합산 |
| 범주 | 평가 미제출 / 늦은 제출 / 평가 점수 낮음 / 학습 접속 부족 / 수강 학점 부담 / 과목 구조 / 재수강·등록 이력 / 인구통계·사회경제 |
| 제공 | 위험을 올리는 사유 **상위 2개**, 기여도 ≥ 0.05 log-odds인 경우만 |
| 검증 | 재학습 모델의 holdout 확률이 03 산출물과 일치(assert) |

**결과 (holdout 명단)**: 91.2%가 개입 가능한 사유 보유. 1순위 사유별 실제 이탈률 — 미제출 41.2%, 학점 부담 33.8%, 늦은 제출 31.9%, 접속 부족 27.2%, 점수 낮음 26.2%(예측 38%, BBB 2014J 영향), 과목 구조 23.4%.
과목별 1순위: BBB 점수 84%, DDD 과목 구조 59%, EEE 접속 68%, CCC 늦은 제출 46%, GGG 인구통계 56%.

## 2. 사용 원칙

- 사유는 **상관 기반 확인 순서**다. 인과 판단이나 학생 평가에 쓰지 않는다.
- **인구통계·사회경제 사유는 지원 서비스 연계에만** 쓰고, 단독으로 대응 강도를 정하지 않는다.
- 과목 구조 사유는 학생 대응이 아닌 **과목 운영팀 전달** 사항이다.
- 업무량: 명단의 86%(3,130명)가 25일에 생기므로 개강 4주차에 인력 집중, 과목별 명단 비율(9.8–52.9%)에 따라 배분.

## 3. 공정성 점검 (holdout, 1차+2차 명단)

| 관점 | 결과 |
|---|---|
| 확률 보정 | 모든 집단 절대 차이 ≤ 3.3%p (55세 이상 n=87 제외, −6.1%p) |
| 명단 비율 | 기준 이탈률을 따름 — 장애 Y 56.2% vs N 38.0% (이탈률 26.5% vs 18.0%) |
| 포착률 | 성별 F 60.4% vs M 65.9%, 장애 Y 78.1% vs N 61.6% |

## 4. 인구통계 제외 모델 비교 (25일 명단)

## 5. 결정

- **최종 모델(인구통계 포함) 유지.** 인구통계를 빼면 장애·학력 포착률 격차는 줄지만(성별·연령은 그대로) 실제 위험이 높은 장애 학생을 과소 예측한다(보정 −7.5%p, 포착 −11.7%p).
- "집단 간 같은 포착률"과 "집단별 정확한 위험" 중 우선할 정의는 **기관 정책**으로 남기고, 두 모델의 교환 관계를 디펜스 자료로 제시한다.
- 재학습 시 공정성 표를 함께 갱신·모니터링한다.
