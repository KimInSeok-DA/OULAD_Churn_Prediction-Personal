# 포트폴리오 요약 — OULAD 학습자 중도이탈 조기 경고 체계

> 온라인 학습자의 중도이탈을 **개강 25일 시점에 예측**하고, 결과를 **관리자가 바로 쓸 수 있는 2단계 위험 등급과 대응 가이드**로 만든 데이터 분석 프로젝트

| 항목 | 내용 |
|---|---|
| 기간 | 2026.07 – 2026.09 |
| 형태 | 스터디 공동 진행(기획·기본 EDA·관측창 후보 분석) → **개인 수행(25일 통합 테이블 확정 이후 전 과정)** |
| 데이터 | Open University Learning Analytics Dataset (OULAD) — 과목 7개, 학기 4개, 등록 32,593건, 클릭 로그 1,065만 행 |
| 도구 | Python (pandas, scikit-learn, XGBoost, statsmodels, matplotlib), Jupyter, Git·GitHub |
| 산출물 | 분석 노트북 12개(관측창 결정 ~ 과목 설계 제안), 최종 분석 보고서, 재현 스냅샷 2개(모델·노트북·산출물·해시, 로컬 보관) |
| 링크 | `README.md`, `docs/최종_분석_보고서.md` |

## 1. 문제

- 이탈을 **학기가 끝난 뒤** 알면 개입할 수 없다. 반대로 너무 일찍 예측하면 신호가 없다.
- 이탈 확률만 주면 현장에서 쓰기 어렵다. **누구에게, 언제, 무엇을** 할지까지 필요하다.

**예측 목표**: 개강 후 25일 시점 재학 중인 수강 27,654건(학생 24,947명)을 대상으로, 25일까지의 학생 정보·학습 활동·평가 행동으로 25일 이후 중도이탈(`Withdrawn`)을 예측한다.

## 2. 핵심 판단과 근거

| 판단 | 근거 |
|---|---|
| **문제 구조: 그 시점 재학생의 이후 이탈** | 초안(4주차 28일, "28일 이내 이탈" 타깃)은 이미 일어난 이탈을 같은 기간 행동으로 맞히는 시간 누수 구조 → 예측 시점·대상·개입 시점이 일치하도록 재정의 |
| **예측 시점 28일 → 25일** | 같은 구조·같은 기준 모델로 25·28·32일 재비교. 28일은 신호가 완만한 구간(26–31일)의 중간이고, 25일은 미제출 신호가 크게 오른 직후. 25일이 개입 대상 이탈자를 가장 많이 남기고(28일 대비 +234건, 32일 대비 +419건) PR-AUC도 가장 높음(0.391 > 0.370 > 0.358) |
| **학생이 아닌 관리자에게 전달** | 위험 통보는 낙인·포기를 굳힐 수 있음. 관리자가 사정을 보고 대응을 고르고, 학생에게는 위험도와 무관한 리마인더를 전원 발송 |
| **단일 임계값 대신 등급 체계** | 단일 기준은 인지 범위·관리자 부담·과목 형평 중 하나를 포기해야 함. 등급으로 세 가지를 나눠 맞춤 |
| **2차 체크포인트는 클릭이 아닌 제출 행동** | 25일 이후 클릭은 같은 등급 안에서 AUC 0.45–0.58로 구분력이 거의 없고, 평가 미제출은 관찰 등급 이탈률을 10.2% → 21.1%로 올림 |
| **최종 모델 XGBoost** | CV는 RandomForest와 사실상 동점(0.4055 vs 0.4061)이지만, 새 학기 적용 성능의 평균·최저가 가장 높고(0.360 / 0.324) 학생별 설명(SHAP)이 내장됨 |

## 3. 결과

### 예측 성능 (새 학기 2014J holdout, 기준을 개발 학기로 고정한 뒤 평가)

| 지표 | 결과 |
|---|---|
| PR-AUC | **0.357** (무작위 0.188의 1.9배) |
| 확률 보정 | 평균 예측 18.0% vs 실제 18.8% |

### 관리자용 2단계 조기 경고 체계

| 단계 | 기준 | 새 학기 결과 |
|---|---|---|
| 1차 (25일) | 고위험 ≥ 40% / 주의 20–40% / 관찰 13–20% 또는 과목 내 상위 30% | 고위험 실제 이탈률 **47.0%**, 등급별 이탈률이 개발 학기 대비 ±3%p 안에서 유지 |
| 2차 (과목별 첫 평가 마감일) | 관찰 등급 + 평가 미제출 → 주의 승격 | 명단 34.2% → **39.6%**, 이탈자 포착 56.1% → **63.8%**, 승격 학생 실제 이탈률 26.6% |

### 개입 지원

- 학생별 SHAP 기여도를 **관리자가 이해할 수 있는 위험 사유**(평가 미제출, 늦은 제출, 접속 부족, 수강 학점 부담 등)로 묶어 상위 2개 제공 → 명단의 **91%**에 개입 가능한 사유 제시
- 사유별 실제 이탈률: 평가 미제출 41.2%, 수강 학점 부담 33.8%, 늦은 제출 31.9%
- 업무량: 명단의 86%가 25일에 생김 → 개강 4주차 인력 집중 제안

### 이탈 요인

- 25일 내 평가 행동(점수·제출 여부·제출 시점) > 과목 구조 > 수강 학점. 평가가 늦은 과목은 학습 접속이 핵심 신호
- 오즈비(과목 통제): 25일까지 점수 없음 2.00배, 점수 10점 증가 0.75배, 수강 학점 30학점 증가 1.14배

### 목적별 과목 설계 제안 (확장 분석)

과목×학기 22개의 설계 지표를 과목·학기 효과를 통제한 상관과 설계 변경 사례 5건의 이중차분으로 분석하고, 제안마다 근거 강도를 붙였다.

| 목적 | 제안 | 근거 강도 |
|---|---|---|
| 조기 탐지 | 3–4주 안 첫 평가에 성적 가중치 (가중치를 낮춘 3개 사례 모두 예측 성능 하락) | 강 |
| 학업 성취 | 촘촘한 소규모 평가보다 간격을 둔 핵심 평가 | 중 |
| 재학 유지 | 설계만으로 이탈을 줄인다는 근거는 약함 → 실험 설계 제안 | 약 |

## 4. 분석 신뢰성을 위해 한 것

| 영역 | 내용 |
|---|---|
| 누수 차단 | 25일 이후 정보·최종 결과 컬럼을 입력에서 제외, 같은 학생이 학습·검증에 동시에 들어가지 않게 학생 단위 그룹 교차검증 |
| holdout 원칙 | 모델·보정기·등급·2차 규칙을 개발 학기로 먼저 고정한 뒤 새 학기에 적용, holdout을 보고 규칙을 바꾸지 않음 |
| 파이프라인 검증 | 최종 모델 확정 전 전체 감사: 원본에서 피처를 독립 재계산해 계산 불일치 0건을 확인하고, 정의 자체의 결함 2건(가중치 0 평가 누락, 재수강 이월의 미제출 오분류)을 찾아 수정 |
| 공정성 | 집단별 확률 보정 차이 ≤ 3.3%p. 인구통계를 뺀 모델과 비교해 "같은 포착률"과 "정확한 위험"의 교환 관계를 제시 |
| 민감도 | 판정이 불명확한 이탈자 93명을 포함해도 결론 불변(PR-AUC 0.357 → 0.382) |
| 교란 통제 | 과목 설계 분석에서 분야·개강 시기 효과를 고정효과로 통제해 착시 관계 2건 제거 |
| 재현성 | 노트북 전체 재실행 오류 0건, 저장 모델로 예측 재현(최대 차이 3e-8), 관측창 결정 비교까지 코드로 재현 |

## 5. 한계와 다음 단계

- 전체 이탈의 **47%는 25일 전에 발생**해 이 모델의 대상이 아니다 → 등록 직후 체크포인트가 별도 과제
- 개입 조치와 과목 설계 제안은 관찰 데이터에서 나온 **가설**이다 → 단계적 도입으로 효과 측정 필요
- 평가 일정이 바뀐 학기는 위험을 과대 표시한다 → 배포 전 일정 점검과 학기별 재보정

## 이력서용 문장

**국문**

```
OULAD 학습자 중도이탈 조기 경고 체계 (2026.07–09, 스터디 공동 기획 이후 단독 수행)
- 개강 25일 시점 재학 수강 27,654건(학생 24,947명)의 이후 이탈을 예측하는 XGBoost 모델 구축, 새 학기 holdout에서 PR-AUC 0.357(무작위 대비 1.9배)과 확률 보정(예측 18.0% vs 실제 18.8%) 달성
- 관리자용 2단계 위험 등급(25일 1차 + 과목별 첫 평가 마감일 2차 승격) 설계로 재학생 39.6%를 명단에 올려 이탈자 63.8% 포착
- SHAP 기반 학생별 위험 사유 코드와 대응 가이드 설계(명단의 91%에 개입 가능한 사유 제시), 인구통계 제외 모델과 비교한 공정성 점검
- 과목×학기 설계 지표를 고정효과·이중차분으로 분석해 목적별 과목 설계 제안 도출(첫 평가 성적 가중치를 낮춘 사례 모두 조기 탐지 성능 하락 확인)
- 최종 확정 전 파이프라인 전체 감사로 피처 정의 결함 2건 발견·수정, 기준 사전 고정 후 holdout 평가, 민감도·재현성 검증
```

**English**

```
Early Warning System for Online Learner Dropout (OULAD, Jul–Sep 2026; solo after study-group planning phase)
- Built an XGBoost model predicting post-day-25 withdrawal for 27,654 active enrollments (24,947 students); PR-AUC 0.357 on an unseen term (1.9x random) with calibrated probabilities (18.0% predicted vs 18.8% actual)
- Designed a two-stage manager-facing risk tier system (day-25 tiers + promotion at each module's first assessment deadline) that flags 39.6% of enrollments and captures 63.8% of dropouts
- Turned SHAP contributions into manager-readable risk reasons (actionable reason for 91% of flagged students) and audited fairness against a no-demographics model
- Derived purpose-specific course design recommendations from module-presentation indicators using fixed effects and difference-in-differences
- Found and fixed two feature-definition flaws in a full pipeline audit (independent recomputation from raw data); fixed all rules before holdout evaluation and verified sensitivity and reproducibility
```
