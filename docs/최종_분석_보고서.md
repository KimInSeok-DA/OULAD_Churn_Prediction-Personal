# OULAD 학습자 중도이탈 조기 경고 체계 — 최종 분석 보고서

- 작성일: 2026-09-13 (최종 갱신 2026-09-14)
- 데이터: Open University Learning Analytics Dataset (Kuzilek, Hlosta & Zdrahal, 2017, *Scientific Data* 4:170171)
- 근거 노트북: `Notebooks/02_Window_Integration/01–05`, `Notebooks/03_Modeling/01–07`
- 모든 수치는 노트북 실행 출력에서 옮겼다. holdout은 2014J 학기(모델·기준 고정 후 평가)다.
- 분석 단위는 학생-과목-학기 수강 1건이다. 한 학생이 여러 과목을 들으면 여러 건이므로, 본문의 "학생 N명"·"명단 N명"은 수강 건 수를 뜻한다.

## 1. 한 장 요약

| 질문 | 답 |
|---|---|
| **무엇을 예측하나** | 개강 후 **25일 시점 재학생**이 **25일 이후 중도 이탈(Withdrawn)**할지 |
| **예측할 수 있나** | 가능하다. 새 학기(2014J)에서 위험 학생을 가려내는 성능(PR-AUC 0.357)이 무작위 선택(0.188)의 **약 1.9배**이고, 예측 확률이 실제와 맞는다(평균 예측 18.0% vs 실제 18.8%) |
| **무엇이 이탈을 가르나** | **25일 내 평가 행동**(점수·제출 여부·제출 시점)이 가장 크고, 다음이 **과목 구조**와 **수강 학점**이다. 평가가 없는 과목은 **접속 활동**이 핵심이다 |
| **결과를 어떻게 쓰나** | **관리자(튜터·학사 담당)용 위험 등급**으로 전달한다. 학생에게 위험 등급을 통보하지 않는다 |
| **과목 설계에는** | 첫 평가에 성적 가중치를 두고 초기 참여를 설계하면 조기 탐지가 좋아진다(근거 강·중). 설계만으로 이탈을 줄인다는 근거는 약하다 |
| **1차(25일) 등급** | 고위험 ≥ 40% / 주의 20–40% / 관찰 13–20% 또는 과목·학기 내 상위 30% / 일반 |
| **2차(과목별 첫 평가 마감일)** | 25일 **관찰** 등급이 그 평가를 **미제출**하면 **주의로 승격** |
| **성과 (holdout)** | 관리자 명단 **39.6%**가 이탈자 **63.8%**를 포착. 고위험 등급의 실제 이탈률 **47.0%** |
| **한계** | 전체 이탈의 **47%는 25일 전에 발생**해 대상이 아니다. 평가 일정이 바뀐 학기(BBB 2014J)는 과대 표시, 기준 이탈률이 오르는 과목(GGG)은 신호가 약하다 |

## 2. 문제 정의

### 2.1 예측 시점과 대상

> 개강 후 25일 시점에 재학 중인 학생을 대상으로, 25일까지 관측 가능한 학생 정보·학습 활동·평가 행동으로 25일 이후 중도 이탈을 예측한다.

| 항목 | 정의 |
|---|---|
| 그레인 | `(id_student, code_module, code_presentation)` 1행 |
| 모델 대상 | 25일 시점 재학 확인 가능 수강 27,661건 (정제 후 27,654건, 학생 24,947명) |
| 타깃 1 | 25일 이후 최종 `Withdrawn` (5,246명, 19.0%) |
| 타깃 0 | 최종 `Pass`, `Distinction`, `Fail` |
| 제외 | 25일까지 이미 취소 4,819명, 25일 이후 등록 20명, 취소일 없는 Withdrawn 93명 |

### 2.2 왜 25일인가

25·28·32일을 같은 조건으로 비교했다. 25일이 **가장 많은 이탈 예정자를 개입 대상으로 남기고**, 같은 조건의 Logistic 기준 모델 성능도 가장 좋았다(PR-AUC 25일 0.391 > 28일 0.370 > 32일 0.358). 근거는 `02_Window_Integration/01_Window_Definition`의 5절(랜드마크 코호트 비교 재현)과 1–4절(21–35일 하루 단위 신호 분석)이다.
늦출수록 제출 정보는 조금 늘지만, 그 사이 신호가 뚜렷한 학생이 먼저 떠나 남은 이탈자를 맞히기가 더 어려워진다.

### 2.3 검증 설계

| 용도 | 방법 |
|---|---|
| 튜닝·모델 비교 | 개발 학기(2013B·2013J·2014B) `StratifiedGroupKFold(5)`, `groups=id_student` (같은 학생이 학습·검증에 동시에 들어가지 않게) |
| 학기 이동 안정성 | 개발 학기 단위 검증(한 학기를 통째로 빼기) — 보조 지표 |
| 최종 평가 | **2014J holdout** — 모델·보정기·등급 기준을 고정한 뒤 평가 |

## 3. 데이터와 피처

### 3.1 25일 코호트 EDA의 핵심 발견

| 발견 | 수치 | 반영 |
|---|---|---|
| 과목 간 기준 이탈률 차이 | GGG 8.0% ~ CCC 30.3% (3.8배) | 과목별 성능·기준 보고 |
| 같은 행동이 과목마다 다른 위험 | 25일 클릭 0회: FFF 43.6% vs GGG 10.3% | 과목 내 순위 조건, 과목별 해석 |
| 평가 일정 변화 | BBB 2014J 첫 TMA 가중치 5 → 0 | 평가 기회 정의 변경 |
| 이월 재수강생 | "전부 미제출"로 섞여 신호 희석(39.2% → 분리 후 41.5%) | 이월 평가 분리 |
| 성별 심슨의 역설 | 전체 남성 +2.2%p → 과목 안에서는 −2.2%p | 성별은 과목 통제 후 해석 |
| 25일 전 이탈 | 전체 이탈의 47.4% (BBB 58.8%) | 한계로 명시 |

### 3.2 최종 피처 20개

| 묶음 | 피처 |
|---|---|
| 학생 배경 | `num_of_prev_attempts`, `studied_credits`, `date_registration` |
| 학습 활동(0–25일) | `total_click_25`, `active_days_25`, `distinct_resources_25`, `no_vle_activity_25` |
| 평가 행동(0–25일) | `n_opportunity_25`, `n_submitted_25`, `avg_score_25`, `avg_submit_delay_25`, `n_banked_25` |
| 인구통계·사회경제 | `gender`, `region`, `highest_education`, `imd_band`, `age_band`, `disability` |
| 과목·개강 시기 | `code_module`, `presentation_period`(B/J) |

- **평가 기회**: 25일까지 마감된 TMA/CMA(가중치 무관) 중 학생에게 이월되지 않은 평가
- **누수 차단**: 25일 이후 정보와 `final_result`, `date_unregistration`은 입력에서 제외
- **공선성**: 평가 행동 5개 컬럼이 항등식 3개로 묶여 있어 3개를 제외(최대 VIF `inf` → 2.95). PCA는 비선형 종속을 찾지 못하고 해석을 잃어 채택하지 않음

## 4. 모델

### 4.1 비교 결과

| 모델 | CV PR-AUC | 학기 단위 PR-AUC (평균 / 최소) | 비고 |
|---|---:|---:|---|
| Dummy | 0.191 | — | 이탈률과 같은 하한선 |
| Logistic | 0.400 | 0.318 / 0.311 | 과목 간 차이 의존도 43%로 최고 |
| RandomForest | 0.406 | 0.343 / 0.296 | 학기 간 흔들림 최대(0.095) |
| **XGBoost (최종)** | 0.406 | **0.360 / 0.324** | 학기 단위 평균·최소 성능 최고 |

- 세 모델의 CV 성능은 **사실상 구분되지 않는다**(1·2위 차이 0.0006 < fold 표준편차 0.015).
- **XGBoost 선택 근거**: 새 학기에 적용했을 때의 평균·최저 성능이 가장 높고(흔들림 자체는 Logistic이 가장 작지만 성능이 가장 낮음), 이탈 요인 해석이 RandomForest와 거의 같으며(순위 상관 0.914), 학생별 설명(SHAP)이 내장돼 있고, 재학습 부담이 작다.
- **확률 보정**: 클래스 가중치 때문에 확률이 부풀려져 있어(예측 0.435 vs 실제 0.191) sigmoid 보정을 적용했다. 순위는 그대로이고 Brier는 0.201 → 0.136이 됐다.
- 과목·학기 내 상대 활동 피처는 사전 규칙(CV·학기 단위 모두 개선)을 충족하지 못해 채택하지 않았다.

### 4.2 holdout 성능 (2014J)

| 지표 | 개발 OOF | holdout |
|---|---:|---:|
| PR-AUC (이탈률 대비) | 0.403 (2.11배) | **0.357 (1.90배)** |
| ROC-AUC | 0.728 | 0.679 |
| 평균 예측 / 실제 이탈률 | 19.1% / 19.1% | 18.0% / 18.8% |

> **holdout 사용 순서**: 사전 규칙상 챔피언이던 RandomForest를 먼저 holdout 평가(0.365)했고, 개발 세트 근거로 XGBoost를 최종 선택한 뒤 XGBoost holdout을 평가했다(0.357). holdout 수치를 보고 모델을 바꾸지 않았다. 차이 0.008은 학기 간 흔들림(0.07–0.09)보다 작다.

## 5. 조기 경고 체계

### 5.1 설계 원칙

1. **관리자에게 전달**: 학생에게 "위험군"을 통보하면 낙인·포기를 굳힐 수 있다. 관리자가 사정을 보고 대응을 고른다. 학생용 마감 리마인더는 전원에게 보낸다.
2. **넓게 인지, 좁게 대응**: 조기 경고를 최대화하되 관리자가 직접 대응하는 명단은 위험도 순으로 좁힌다.
3. **두 단계**: 25일에 곧 떠날 학생을 잡고, 늦게 떠나는 학생은 과목별 첫 평가 마감일에 실제 행동으로 다시 점검한다.

### 5.2 1차(25일) 등급

| 등급 | 조건 (보정 이탈 확률) | 관리자 대응 | holdout 비율 | holdout 실제 이탈률 |
|---|---|---|---:|---:|
| 1 고위험 | ≥ 40% | 즉시 연락·면담 | 6.7% | **47.0%** |
| 2 주의 | 20–40% | 모니터링·맞춤 안내 | 27.6% | 26.9% |
| 3 관찰 | 13–20% 또는 과목·학기 내 상위 30% | 2차 점검 대상 | 21.3% | 17.7% |
| 4 일반 | 나머지 | 없음 | 44.5% | 10.1% |

**선정 논리**

| 경계 | 논리 |
|---|---|
| 40% | 즉시 연락 대상 두 명 중 한 명은 실제 이탈 |
| 20% | 전체 평균 이탈률(19%) 이상이면 관리자 명단 |
| 13% | 관리자 대응 없이 이탈자 80%를 인지하는 선(개발 세트) |
| 과목 내 30% | 관리자 명단을 늘리지 않고 기준 이탈률이 낮은 과목(GGG)의 방치를 막음 |

**조정 규칙**: 관리 인력이 부족하면 주의 하한을 25%로 올린다(holdout 명단 34.2% → 26.0%, 포착률 56.1% → 45.9%).

### 5.3 2차(과목별 첫 평가 마감일) 규칙

| 항목 | 내용 |
|---|---|
| 체크포인트 | 25일 이후 첫 TMA/CMA 마감일: CCC 32 / EEE 33 / BBB 40–54 / DDD 41–53 / FFF 47–52 / AAA 54 / GGG 61일 |
| 규칙 | 25일 **관찰** 등급이 그 평가를 **미제출** → **주의 승격** |
| 선정 원칙 | 승격 집단의 실제 이탈률 ≥ 20%(주의 기준과 같은 의미), 개발 세트로 판단 |

- 25일 이후 **클릭 변화는 같은 등급 안에서 거의 구분력이 없고**(AUC 0.45–0.58), **평가 미제출은 관찰 등급 이탈률을 10.2% → 21.1%로 두 배** 올린다.
- 일반 등급 미제출(14.0%)은 승격 원칙(20%)에 못 미쳐 제외했다(holdout에서는 21.9% — 다음 학기 재검토 후보).

### 5.4 체계 전체 성과 (holdout)

| 지표 | 1차만 | 1차 + 2차 |
|---|---:|---:|
| 관리자 명단 | 34.2% | **39.6%** |
| 이탈자 포착률 | 56.1% | **63.8%** |
| 명단 적중률 | 30.8% | 30.2% |
| 61–120일 이탈자 포착 | 54.4% | 64.1% |
| 121일 이후 이탈자 포착 | 48.5% | 55.8% |

- 26–32일에 떠난 학생의 75%가 25일 명단에 있었다.
- 2차로 승격된 학생의 실제 이탈률은 **26.6%**로 25일 주의 등급과 같다. 25일 모델이 볼 수 없던 위험을 잡는다.

### 5.5 다른 방식을 쓰지 않은 이유

| 방식 (개발 세트) | 관리자 명단 | 포착률 | GGG 포착률 | 한계 |
|---|---:|---:|---:|---|
| F1 최대 단일 기준 | 31.3% | 59.0% | 0% | 대응 강도 구분 불가, GGG 방치 |
| Recall 80% 단일 기준 | 56.5% | 80.0% | 7% | 재학생 절반 이상이 관리자 대응 대상 |
| 전역 상위 20% | 20.0% | 44.1% | 0% | 이탈자 절반 이상 누락 |
| 과목 내 상위 30%만 | 30.0% | 51.0% | 36% | 고이탈 과목의 위험 학생까지 잘림 |
| **A안 1차 등급** | 33.5% | 61.1% | 36%(관찰 포함) | — |

단일 기준은 **인지 범위, 관리자 부담, 과목 형평** 중 하나를 포기해야 한다. 등급 체계는 세 가지를 나눠서 맞춘다.
주의 하한은 부담과 효과를 가장 크게 움직이는 경계다. 15%면 명단 48%로 과부하가 되고, 25%면 명단은 25%로 줄지만 이탈자의 49%가 명단 밖에 남는다(개발 세트).

## 6. 이탈 요인

### 6.1 중요도 (세 모델 공통)

| 순위 | 요인 | 근거 |
|---|---|---|
| 1 | **25일 내 평가 점수** | 세 모델 모두 1위. 약 55–60점 아래부터 위험 증가 |
| 2 | **과목 구조** | 과목별 기준 이탈률(AAA 기준 GGG 0.17배 ~ DDD 2.15배) |
| 3 | **제출 시점·제출 여부** | 마감일을 넘기면 위험이 계단형으로 상승. 점수 신호의 약 1/3이 "제출 여부" |
| 4 | **수강 학점** | 90학점부터 위험 증가 |

### 6.2 방향과 크기 (Logistic 오즈비, 다른 요인 통제)

| 요인 | 오즈비 [95% CI] |
|---|---|
| 25일까지 점수 없음 | 2.00 [1.43, 2.80] |
| 점수 10점 증가 | 0.75 [0.73, 0.77] |
| 마감 대비 제출 하루 늦음 | 1.05 [1.03, 1.07] |
| 수강 학점 30학점 증가 | 1.14 [1.10, 1.17] |
| 장애 있음 | 1.56 [1.38, 1.76] |
| 남성 (여성 기준, 과목 통제) | 0.79 [0.72, 0.87] |

### 6.3 과목별 차이

- 25일 내 평가가 있는 과목(BBB·CCC·DDD·FFF): 세 모델 모두 평가 점수·제출 시점이 1위 (AAA는 검증 표본이 작아 해석 보류)
- **평가가 33일에야 있는 EEE: 학습 접속이 1위**
- 61일까지 평가가 없는 GGG: 어떤 요인도 크게 기여하지 못함(25일 정보로 구분이 어려움)

> 중요도·오즈비는 **연관**이며 인과 효과가 아니다.

## 7. 관리자 개입 가이드

### 7.1 위험 사유 코드

학생별 SHAP 기여도를 관리자가 이해할 수 있는 사유로 묶어 **상위 2개**를 제공한다. holdout 관리자 명단의 **91.2%**가 개입 가능한 사유를 갖는다.

## 10. 목적별 과목 설계 제안

근거: `03_Modeling/07_Course_Design_Indicators`. 과목×학기 22개의 설계 지표(평가 수·시점·가중치, 학습 자료, 초기 참여)와 결과 지표의 관계를
**네 수준**(전체 / 과목 내 / 과목·학기 고정효과 / 과목 평균)과 **설계 변경 사례 5건의 이중차분**으로 확인했다. 인과 효과가 아니라 설계 가설의 근거 강도다.

| 목적 | 제안 | 핵심 근거 | 강도 |
|---|---|---|---|
| 조기 탐지 | 3–4주 안 첫 평가에 **성적 가중치**를 둔다 | 첫 평가 가중치를 낮춘 3개 사례 모두 ROC-AUC 하락(−0.06 ~ −0.09), 고정효과 상관 +0.64 | 강 |
| | 개강 후 3–4주 **참여 활동**을 설계한다 | 25일 클릭 × 예측 성능, 네 수준 모두 양의 상관 | 중 |
| 학업 성취 | 작은 평가를 촘촘히 늘리기보다 **간격을 둔 핵심 평가** 중심 | 평가 수 × 완주자 합격률 −0.5 ~ −0.8(네 수준), 평가 삭제 +4.6%p / 추가 −6.8%p | 중(성적 산출 방식 변화와 구분 불가) |
| 재학 유지 | 설계만으로 이탈을 줄인다는 제안은 하지 않음. 초기 평가 시점 조정을 **실험 후보**로 둠 | 통제 후 일관된 관계 없음, 사례 방향 혼재. 이탈률 차이는 분야(STEM 21.4% vs 사회과학 12.4%)가 큼 | 약 |
| 관리자 운영 | 초기 평가를 도입할 때 **인력 계획**을 함께 세운다 | 25일 내 평가 수 × 명단 비율 +0.46 ~ +0.80, 사례 2건 명단 +18%p | 강 |
| 재학습 안정성 | 학기 간 평가 일정·가중치를 유지하고, 바꾸면 배포 전 점검 | BBB 2014J 설계 변경 후 PR-AUC 배수 −0.58(사례 중 최대) | 강 |

- **목적 간 교환 관계**: 초기 평가는 조기 탐지를 높이지만 관리자 명단을 키운다.
- **권장 조합**: 3–4주 안 가중치 있는 핵심 평가 1개 + 간격을 둔 소수 핵심 평가 + 학기 간 일정 유지.
- 과목별 적용 예: GGG는 조기 체크포인트, BBB는 첫 평가 가중치 복원, DDD는 평가 과밀 회피.

## 11. 한계와 향후 과제

### 한계

1. **25일 전 이탈(전체의 47%)은 대상이 아니다.** 초기 이탈은 등록 직후 관리가 필요한 별도 과제다.
2. **새 학기 평가 일정 변화에 민감하다.** BBB 2014J는 25일 내 평가가 가중치 0이 되어, BBB 학생 중 관리자 명단 비율이 개발 학기 25.4%에서 44.9%로 늘었지만 주의 등급 실제 이탈률은 15.3%에 그쳤다(과대 표시).
3. **기준 이탈률이 변하는 과목**(GGG 4.0% → 8.1% → 12.9%)은 과거 기준 보정으로 해결되지 않는다.
4. **개입 방향은 가설이다.** 연관 분석에서 나왔으므로 실제 효과는 운영 실험으로 검증해야 한다.
5. 학기 단위 검증은 학습에 없는 범주 때문에 2개 fold만 가능했다.

## 부록 A. 예상 질문과 답변

**Q1. 왜 25일인가? 더 늦추면 정보가 많아지지 않나?**
늦추면 제출 정보는 조금 늘지만, 신호가 뚜렷한 학생이 먼저 떠나 남은 이탈자를 맞히기 어려워진다. 같은 조건에서 25일 PR-AUC가 가장 높았다(0.391 > 0.370 > 0.358). 대신 늦은 이탈자는 2차 체크포인트로 보완했다.

**Q2. PR-AUC 0.357은 낮지 않나?**
이탈률이 약 19%인 문제에서 무작위 PR-AUC는 0.19다. 최종 모델은 그 1.9배이고, 새 학기에서도 확률이 실제와 맞는다(18.0% vs 18.8%). 성격이 다른 세 모델의 CV 성능이 모두 같은 수준(0.40)에 머문 것은, 성능 상한이 모델 선택보다 25일 시점 정보량에서 온다는 점을 시사한다.

**Q3. RandomForest holdout이 더 높았는데 왜 XGBoost인가?**
모델은 개발 세트의 학기 단위 성능·해석·운영성으로 먼저 정했다. holdout을 보고 바꾸면 holdout을 모델 선택에 쓰는 것이 된다. 차이(0.008)는 학기 간 흔들림(0.07–0.09)보다 작다.

**Q4. 왜 학생이 아니라 관리자에게 알리나?**
위험 통보가 학생의 포기를 굳히거나 낙인이 될 수 있고, 오탐 학생에게 불필요한 불안을 준다. 관리자는 학생 사정을 보고 대응 방식을 고를 수 있다. 학생에게는 위험도와 무관한 리마인더를 전원 발송한다.

**Q5. 경계값 40/20/13%는 임의로 정한 것 아닌가?**
각 값에 운영 의미를 부여했다. 40%는 연락 대상 두 명 중 한 명이 실제 이탈, 20%는 평균 이탈률, 13%는 이탈자 80% 인지 선이다. 민감도 분석에서 다른 값의 교환 비율을 모두 제시했고, 새 학기에서도 등급별 이탈률이 ±3%p 안에서 유지됐다.

**Q6. 기관이 경계값을 바꾸면?**
운영 판단이다. 민감도 표가 영향 예측표 역할을 한다. 인력이 부족할 때의 공식 조정안(주의 하한 25%)도 미리 정해뒀다.

**Q7. 인구통계 피처를 쓰는 것은 차별 아닌가?**
빼면 장애·학력 집단의 포착률 격차는 줄지만, 실제 위험이 높은 장애 학생을 과소 예측한다. 최종 모델을 유지하되 인구통계 사유는 지원 연계에만 쓰고 단독으로 대응 강도를 정하지 않도록 했다. 공정성 정의 선택은 기관 정책으로 남겼다.

**Q8. 2차 체크포인트에 왜 클릭을 쓰지 않았나?**
25일 이후 클릭 변화는 같은 등급 안에서 이탈을 거의 구분하지 못했다(AUC 0.45–0.58). 제출하고 활동이 줄어든 학생의 이탈률도 활동을 유지한 학생과 같았다. 반면 평가 미제출은 관찰 등급 이탈률을 두 배로 올렸다.

**Q9. 취소일 없는 Withdrawn 93명을 빼서 성능을 부풀린 것 아닌가?**
이 학생들의 25일 행동은 25일 전 이탈자와 비슷했다. 2014J의 87명을 모두 이탈자로 포함하는 상한 시나리오에서도 성능은 오히려 올랐고(0.357 → 0.382) 결론은 바뀌지 않았다.
